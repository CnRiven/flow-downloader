# 拾流 Flow v1.0.2 · macOS 自动安装引擎

本次更新 macOS 客户端，Android 继续使用 [1.0.1 安装包](https://github.com/CnRiven/flow-downloader/releases/download/v1.0.1/Flow-Android-1.0.1-debug.apk)。

## 下载与安装

下载 `Flow-macOS-1.0.2-arm64.zip`，解压后将「拾流.app」放入「应用程序」，替换旧版。适用于 Apple Silicon / macOS 13+。历史记录和设置继续保留。

## 自动准备 yt-dlp

- 检测到没有可运行的 yt-dlp 时，自动下载官方 macOS 独立引擎，不要求用户先装 Homebrew、Python，也不要求管理员密码或 GitHub 登录。
- 安装到 `~/Library/Application Support/Flow/engines/bin/yt-dlp`，优先识别应用管理的引擎。
- 显示安装进度，提供取消、失败重试和偏好设置中的更新 / 修复入口。
- 下载后进行 SHA-256 校验和版本运行检查，再启用新引擎；失败或取消时保留原有安装。
- 安装期间发起的视频解析或加入队列操作，准备好引擎后继续执行。

首次安装需要网络访问 GitHub。FFmpeg 和 Deno 是独立可选组件：没有 FFmpeg 时视频选择自带声音的单文件格式；分离音视频合并和 MP3 转换仍需要 FFmpeg。部分 YouTube 功能需要 Deno。

## 验证

自动检查覆盖校验失败、版本不一致、非官方地址、非法版本路径、断网、取消、旧引擎保留和临时文件清理。真实 GUI 测试在隔离目录和空系统搜索路径下完成了官方引擎安装、安装后自动继续解析与下载、再次启动复用；下载结果与本地测试视频逐字节一致。

安装包采用本地 ad-hoc 签名，尚未完成 Apple Developer ID 签名和公证。仍为预览版。

附件同时包含本版本源码、第三方说明和 `SHA256SUMS.txt`。Android 及其运行时源码附件保留在 v1.0.1 发布页面。
