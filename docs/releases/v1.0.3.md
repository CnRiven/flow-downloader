# 拾流 Flow v1.0.3 · macOS 进度与交互优化

下载 `Flow-macOS-1.0.3-arm64.zip`，解压后替换旧版「拾流.app」。适用于 Apple Silicon / macOS 13+，保留历史记录和设置。

## 修复进度回退

- 汇总整个任务的音视频轨道进度，有大小信息时按大小分配权重，否则按轨道数估算。
- 切换轨道、大小估算变化、暂停后继续，不会让已显示的进度倒退。
- 传输阶段最多 95%，合并、转换和输出文件检查完成后才显示 100%；未知大小时显示等待动画。
- 仅在真正进入后处理时显示合并 / 转换，避免每条轨道完成时反复切换状态。
- 减少进度刷新带来的历史文件写入；完成、暂停和退出时及时保存。

## 优化解析和加入队列

- 解析立即显示忙碌状态、计时和取消入口，连续点击不会重启解析。
- 未修改链接与浏览器选项时复用已有预览，修改链接或取消后丢弃旧结果。
- 加入队列立即创建任务并关闭弹窗，后续引擎准备和视频信息获取在任务列表中进行；解析期间也可直接加入。
- 拦截相同链接、格式、目录和浏览器选项的未完成任务，并显示已在队列中的提示。
- 重复点击恢复不会重复创建下载进程，等待引擎时仍可暂停任务。

## 验证与安装说明

通过核心检查、原生模型交互检查，以及真实本地视频、MP3 转换、DASH 独立音视频下载合并和 HTTP Range 续传测试。实际应用使用隔离目录验证无引擎时立即入队、后台安装后下载、再次启动复用引擎，下载文件与测试源逐字节一致。

yt-dlp 缺失时仍自动从官方下载安装。FFmpeg 用于合并与 MP3 转换，Deno 用于部分 YouTube 功能，属于可选组件。首次安装引擎需要访问 GitHub。站点响应和网络状况仍会影响解析耗时。

安装包采用本地 ad-hoc 签名，尚未完成 Apple Developer ID 签名和公证，仍为预览版。附件包含本版本源码、第三方说明和 SHA-256 校验值。

本次仅更新 macOS；[Android 1.0.1 安装包及运行时源码](https://github.com/CnRiven/flow-downloader/releases/tag/v1.0.1) 保留在原发布页面。
