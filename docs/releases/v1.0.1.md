# 拾流 Flow v1.0.1 · 预览版

本次发布包含 Android 1.0.1 和 macOS 1.0.0 的已编译应用。

## 下载与安装

- **Android**：下载 `Flow-Android-1.0.1-debug.apk`，在 Android 10+ 设备安装。包含 arm64-v8a、armeabi-v7a、x86_64，约 151 MiB。使用与此前相同的开发签名，可以覆盖安装旧测试版并保留记录。
- **macOS**：下载 `Flow-macOS-1.0.0-arm64.zip`，解压后把「拾流.app」移入「应用程序」。适用于 Apple Silicon / macOS 13+。这是本地签名构建，尚未完成 Apple Developer ID 签名与公证。

Mac 使用本机安装的下载组件。缺少组件时运行：

```sh
brew install yt-dlp ffmpeg deno
```

Android 已内置下载运行时，不需要安装 Python、FFmpeg 或 Termux。

## 主要功能

- 视频链接解析，最佳画质、1080p、720p 和 MP3 选择。
- 下载队列、暂停续传、历史记录和文件定位。
- Android 支持整段抖音分享文案、短链接以及 `iesdouyin.com/xg/video/...` 地址转换。
- Android 内置 yt-dlp 2026.10.26，覆盖安装时升级旧版引擎。
- Android 新增官方抖音网页验证，以及用户主动选择当前播放视频的保存入口。

## 验证与限制

- macOS 通过本地真实视频下载、MP3 转换和 HTTP Range 断点续传测试。
- Android 通过 8 项单元测试、Lint、APK 签名校验，以及 Android 15 / arm64 模拟器的升级、视频下载、MP3 转换和 MediaStore 导出测试。
- 尚未完成 Android 真机兼容性测试。抖音可能要求手动完成官网验证码或登录；未承诺所有抖音视频都能下载。

## 源码、组件与校验

- `Flow-1.0.1-source.zip`：该发布标签对应的项目源码、构建脚本、测试和许可证。
- `Flow-runtime-wrapper-sources-0.18.1.zip`：上游运行时封装的 Maven 源码包、构建说明和来源记录；原生 FFmpeg/Python 及依赖来源参见其中的说明和 `THIRD_PARTY_NOTICES.md`。
- `SHA256SUMS.txt`：安装包和源码附件的 SHA-256 校验值。
- 应用采用 GPL-3.0-or-later，第三方组件遵循各自许可证；见 `LICENSE` 与 `THIRD_PARTY_NOTICES.md`。

在 macOS 或 Linux 上可在下载目录运行 `shasum -a 256 -c SHA256SUMS.txt` 检查所有附件。
