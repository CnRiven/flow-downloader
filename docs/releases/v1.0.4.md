# 拾流 Flow v1.0.4 · macOS 抖音分享文案与网页登录

下载 `Flow-macOS-1.0.4-arm64.zip`，解压后替换旧版「拾流.app」。适用于 Apple Silicon / macOS 13+，保留原有下载历史和设置。

## 使用方法

1. 直接粘贴抖音整段分享文案，例如包含「复制此链接，打开抖音」和 `v.douyin.com` 短链接的文字。
2. 需要登录或验证时，点击「抖音登录 / 验证」，在可见的抖音官方网页手动完成操作。
3. 点击「保存状态并重试」，将本机网页状态提供给抖音任务。偏好设置中可以清除状态。
4. 若常规解析仍失败，在官方页面播放目标视频后，点击「使用当前视频」。该方式使用当前播放器提供的单文件，画质取决于网页播放器。

## 验证与限制

用户提供的真实短链接已解析到视频 `7651105998492519707`。通过分享文案、跳转限制、Cookie 作用域和登录引导检查，以及隔离 WebKit 中 Cookie 导出、清除、权限和临时文件清理检查。真实 yt-dlp 的网页视频元数据下载、本地视频、MP3、独立音视频合并和断点续传均通过回归测试。

未使用用户的真实账号或浏览器 Cookie。示例在未登录环境中返回 `403 / Fresh cookies`，已接入网页登录引导；未验证该示例登录后的实际下载。站点风控、账号权限和网络仍可能影响结果。blob、加密视频及仅限抖音 App 播放的页面暂不支持「使用当前视频」。

yt-dlp 缺失时会从官方自动安装；FFmpeg 和 Deno 仍为可选组件。安装包采用本地 ad-hoc 签名，尚未完成 Apple Developer ID 签名和公证，仍为预览版。

附件包含 macOS 安装包、本版本源码、第三方说明和 SHA-256 校验值。Android 仍使用 [1.0.1 发布页](https://github.com/CnRiven/flow-downloader/releases/tag/v1.0.1) 的安装包。
