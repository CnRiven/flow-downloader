# 拾流 Flow v1.0.5 · 修复抖音登录后仍无法下载

下载 `Flow-macOS-1.0.5-arm64.zip`，解压后替换旧版「拾流.app」。适用于 Apple Silicon / macOS 13+，保留历史记录和已保存的本机网页登录状态。

## 问题与修复

旧版保存登录状态后仍调用被抖音拒绝的常规解析；「使用当前视频」只读取播放器的 `currentSrc`，遇到 blob 播放器时无法取得实际媒体地址。

新版从网页已加载的播放响应、首屏渲染状态和播放器组件中读取普通媒体地址，匹配当前视频 ID 后交给下载引擎。支持 Fetch、XHR、首屏 JSON、camelCase 地址数组和普通媒体的 blob 播放器。加密流仍不支持。

登录后常规解析失败的提示会明确说明「已保存网页状态，但常规解析仍被拒绝」，引导读取网页视频，避免反复登录。视频已识别时，两个保存入口都会使用已识别的播放地址；仅保存登录状态不会立即关闭目标网页并重复失败请求。

## 使用方法

1. 在失败任务下点击「抖音登录 / 验证后重试」。
2. 在官方网页播放目标视频；已登录时无需重复登录。
3. 点击「读取网页视频并下载」，或在显示「使用已识别视频」后直接使用。

## 实际验证

示例视频 `7651105998492519707` 已在原生应用中下载完成。文件大小 178,809,979 字节，时长 1010.966667 秒，1440 × 1080 H.264 视频和 AAC 音频。

通过真实 WebKit 受控页面的 Fetch / XHR、首屏数据和播放器组件读取、相关视频隔离及页面内导航检查，以及原有视频、MP3、音视频合并、断点续传和交互回归检查。

网页登录状态仅保存在本机。页面响应只提取视频 ID、标题、时长和媒体地址；临时文件使用私有权限并在请求结束时清理。源码与安装包不包含用户 Cookie、测试视频或签名播放地址。

安装包仍为本地 ad-hoc 签名的预览版，尚未完成 Apple Developer ID 签名与公证。Android 继续使用 [1.0.1 发布页](https://github.com/CnRiven/flow-downloader/releases/tag/v1.0.1) 的安装包。

真实示例的完整音视频解码检查通过（FFmpeg 逐帧 / 逐音频包读取全片，无解码错误）。
